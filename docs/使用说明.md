# AI 摄影预约管家 · 使用说明

## 一、这是什么

一个接入 DSH（deepseek-harness-java）的摄影工作室 AI 助手。前端是运营工作台，右侧 AI 助手可以直接帮你查套餐、查摄影师、预约拍摄、查订单、看运营数据——全程自然语言，无需点菜单。

## 二、启动步骤

1. **启动业务应用**（端口 18114）：
   ```bash
   SERVER_PORT=18114 java -jar p-app/target/p-app-1.0.0-SNAPSHOT.jar
   ```
2. **确认 DSH 已运行**（端口 8090）且 `photo-copilot` 插件已安装激活：
   ```bash
   curl -s http://127.0.0.1:8090/api/harness/plugins | grep photo-copilot
   ```
3. **打开工作台**：浏览器访问 http://127.0.0.1:18114

## 三、AI 能做什么（试试这些话）

| 你说 | AI 做 |
|------|-------|
| 「证件照多少钱？多久出片？」 | 调 `plan_list`，列出套餐价格与出片时效 |
| 「有哪些摄影师？擅长什么？」 | 调 `photographer_list`，返回特长与评分 |
| 「帮我预约个人写真，周五 14:00，摄影师阿哲，穆先生 13800555555」 | 调 `book`，**先复述要素请你确认**，确认后预约并给单号 |
| 「查一下订单 F5001 的状态」 | 调 `order_info`，返回详情与状态 |
| 「今天整体运营情况怎么样？」 | 调 `stats`，订单/营收/建议一览 |

## 四、业务规则

- **预约确认制**：AI 预约前必须复述套餐、价格、摄影师、拍摄时间，经你确认后才真正接单。
- **编号规则**：订单号 `F5001+`。
- **默认摄影师**：预约未指定摄影师时默认分配阿哲（G01，人像/写真）。
- **优惠规则**：工作日拍摄享 9 折；加精修 30 元/张。
- **拍摄提醒**：提前 15 分钟到店试装；可自带服装道具；婚礼跟拍为双机位全程。

## 五、常见问题

**Q：AI 一直显示「…」不动？**
AI 可能在调用 `ask_user_question` 等待你补充信息（如缺少拍摄时间）。把信息补齐重发即可；若仍卡住，等待约 1-2 分钟或重启 DSH 后重试。

**Q：插件激活失败 / 调用了旧工具？**
先卸载再重装：`POST /api/harness/plugins/photo-copilot/uninstall`，删除 `~/.dsh/standalone/plugins/photo-copilot.jar` 残留，重新 install + activate，并重启 DSH 以清空会话缓存。

**Q：换端口怎么改？**
应用端口：`SERVER_PORT=xxx` 环境变量；插件连应用端口：环境变量 `PHOTO_APP_BASE_URL`（默认 `http://127.0.0.1:18114`）。
